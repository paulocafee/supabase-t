## instalado
npm install @supabase/supabase-js react-native-url-polyfill --legacy-peer-deps

## Passo 1: Criar a Conta e o Projeto no Supabase
Acesse supabase.com e faça login (pode usar sua conta do GitHub).

Na página principal, clique em "New Project" (Novo Projeto).

Preencha os dados do projeto:

Name: crud-alunos (ou o nome que preferir).

Database Password: Crie uma senha forte e guarde-a.

Region: Escolha a mais próxima (ex: South America / São Paulo).

Plan: Mantenha no plano gratuito (Free Tier).

Clique em "Create new project" e aguarde cerca de 1 a 2 minutos até o banco terminar de subir.

## Passo 2: Criar a Tabela no Banco de Dados
1. No menu lateral esquerdo do Supabase, clique no ícone SQL Editor (parece um terminal/código).
2. Clique em "New Query" no topo.
3. Cole o código abaixo na área de texto:


```sql
-- 1. Criar a tabela 'contacts' com os 3 campos (mais id e data de criação)
create table public.contacts (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text not null,
  email text not null,
  phone text not null
);

-- 2. Habilitar a segurança por linha (RLS)
alter table public.contacts enable row level security;

-- 3. Criar uma regra pública para permitir Ler, Inserir, Editar e Excluir sem autenticação
create policy "Acesso Liberado para Aula" 
on public.contacts 
for all 
using (true) 
with check (true);
```

4. Clique no botão "Run" (ou pressione Ctrl + Enter).
5. Você verá a mensagem "Success. No rows returned".
> Observação: Se quiser visualizar sua tabela criada, vá no menu lateral esquerdo e clique em Table Editor -> contacts.


Passo 3: Pegar as Chaves de API do Supabase
Para conectar o app ao banco, você precisa da URL e da chave anônima (ANON KEY):

No menu lateral do Supabase, vá em Project Settings (ícone de engrenagem no canto inferior esquerdo).

No menu que abrir, clique em API.

Copie as duas informações que aparecem na tela:

Project URL (ex: [https://xyzcompany.supabase.co](https://xyzcompany.supabase.co))

anon public (chave longa de API no bloco Project API keys)

Passo 4: Configurar as Variáveis no React Native Expo
No seu projeto React Native, crie um arquivo chamado .env na raiz do projeto (no mesmo nível do arquivo package.json).

Cole as chaves que você copiou do Supabase dentro dele:

Snippet de código
EXPO_PUBLIC_SUPABASE_URL=cole_aqui_a_sua_Project_URL
EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY=cole_aqui_a_sua_chave_publishable
(Lembre-se de não colocar aspas e nem espaços ao lado do sinal de igual).

> Observação: dependendo da versão do Supabase, essa chave pode aparecer como
> "anon public" ou como "publishable" na tela de API Keys. Nos dois casos, é a
> chave pública, segura para ficar no app. Nunca use a "service_role" no app!

## Passo 5: Instalar as dependências do Supabase no projeto
No terminal, dentro da pasta do projeto, rode:

```bash
npx expo install @supabase/supabase-js @react-native-async-storage/async-storage react-native-url-polyfill
```

- **@supabase/supabase-js**: biblioteca oficial que sabe "conversar" com o Supabase.
- **@react-native-async-storage/async-storage**: guarda a sessão do usuário no celular.
- **react-native-url-polyfill**: faz o React Native entender URLs do jeito que o Supabase espera.

## Passo 6: Criar o cliente de conexão (src/services/supabase.ts)
Esse arquivo é criado UMA ÚNICA VEZ e reutilizado em todo o app. Ele lê as
variáveis do `.env` e monta a conexão:

```ts
import 'react-native-url-polyfill/auto';
import AsyncStorage from '@react-native-async-storage/async-storage';
import { createClient } from '@supabase/supabase-js';

const urlDoSupabase = process.env.EXPO_PUBLIC_SUPABASE_URL;
const chaveDoSupabase = process.env.EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY;

export const supabase = createClient(urlDoSupabase!, chaveDoSupabase!, {
  auth: { storage: AsyncStorage, autoRefreshToken: true, persistSession: true, detectSessionInUrl: false },
});
```

> DICA: nunca crie um `createClient` dentro de uma tela. Sempre importe o
> `supabase` já pronto deste arquivo (`import { supabase } from '@/services/supabase'`).

## Passo 7: Criar a camada de serviços (src/services/contatos.ts)
Em vez de chamar o Supabase direto dentro das telas, concentramos as
funções de banco de dados em um só lugar. Isso deixa o código mais fácil
de entender e de dar manutenção:

- `listarContatos()` → busca todos os contatos (SELECT). Doc: https://supabase.com/docs/reference/javascript/select
- `criarContato(dados)` → cadastra um novo contato (INSERT). Doc: https://supabase.com/docs/reference/javascript/insert
- `atualizarContato(id, dados)` → edita um contato existente (UPDATE). Doc: https://supabase.com/docs/reference/javascript/update
- `excluirContato(id)` → remove um contato (DELETE). Doc: https://supabase.com/docs/reference/javascript/delete
- `buscarContatoPorId(id)` → busca um único contato (bônus, também é um SELECT). Doc: https://supabase.com/docs/reference/javascript/select

> DICA: toda função do service segue o mesmo padrão: chama o Supabase,
> confere se veio `error` e, se vier, lança uma exceção com `throw new Error(...)`.
> Assim as telas só precisam usar `try/catch` para tratar problemas.

## Passo 8: Usar o service nas telas
- **src/app/cadastrar.tsx**: chama `criarContato` (cadastro novo) ou
  `atualizarContato` (quando a tela é aberta em modo edição, a partir do
  botão "Editar" da lista).
- **src/app/consultar.tsx**: chama `listarContatos` assim que a tela abre
  (dentro de um `useEffect`) e `excluirContato` no botão "Excluir" de cada item.

> DICA: se a lista não atualizar depois de cadastrar um novo contato, dê um
> "puxar para atualizar" (pull to refresh) na tela de consulta — ela chama
> `carregarContatos()` de novo automaticamente.
